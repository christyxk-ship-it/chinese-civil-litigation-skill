# 庭上编

两节各有口令：「庭审速查」用第一节，「法条速查」用第二节；只点名本编未说口令的，按所问内容选节。「法条速查」庭外也可用。

## 一、庭审速查

庭上用：只就案件目录现有文件作答，有开庭提纲先翻它。

- 结论先行，一两句，带出处（文件＋页或节）。
- 只搬材料里已有的结论与原文。
- **材料里没有的，直接答「现有材料里没有」**——庭上说出口的收不回。

## 二、法条速查

先查库再开口，不凭训练数据写条号与事实。只引核验过的有效版本：默认现行有效，律师指定时点的取该时点版本；库里查到的与记忆不符，以库为准。

| 线 | 源（按序） | 交付须带 |
|---|---|---|
| 法条 | 北大法宝 → 华宇元典 | 法规全称、条号、条文原文、时效性、施行日期 |
| 案例 | 北大法宝 → 华宇元典 | 案号、法院、审级、审结日期、裁判要旨 |
| 企业 | 启信慧眼 → 天眼查 → 华宇元典企业库 | 统一社会信用代码、法定代表人、注册资本、成立日期、经营状态；涉诉的另核被执行与失信记录 |

- 顺序同 `references/起草与审查.md` 第一节，也可以换用其他数据库：前一家出故障或查无结果才换下一家，答案末尾写明哪家出了什么错。两线以上并发查。
- 企业简称或线索模糊的先取全称，多个候选列给律师确认，不自动取第一条。
- 没核到的标「待核验」并写明缺哪一项，不凭记忆补。
