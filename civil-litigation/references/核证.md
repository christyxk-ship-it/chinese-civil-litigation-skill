# 核证编

两段：出问卷、回收。

## 出问卷

只问对方知道而我们缺的。
- 收件人从 README 推定，问题从举证附注、搜证报告、检索要点清单的缺口推定；推不准收件人时问律师。当面核实的，动笔前问律师见哪几位、各自分管什么。
- 从前序产物推题前，先在案卷里核对：前序标「缺」的先在案卷里找，找到的不再问客户；前序文件之间、产物与案卷实物之间的出入，写进对照表「与前序文件的出入」。
- **一人一份**核证问卷 .docx，按人出稿，一人兼数职的相关题目并入一份：目的、背景一段、作答说明（可答「不知道」、可部分作答）→ 按主题分组、最要紧在前、每题一问，每题下另起一段写「答：」，后留一个空段，不用表格方框 → 末尾「还有什么我们没问到但该知道的」。
- 一次不超过 20 题，只留对方最可能当场答出、且我方最缺的；其余题目列进对照表，标「下轮」。
- 与对外口径冲突的事实，列进问卷前先问律师客户是否已有口径；能在线核实的先核实（如现网页面），核实结果写进对照表，问卷只问尚未确认的部分，并提示统一表述。
- 另出内部对照表 .md：题号 → 争点 → 证明目的 → 急缓；时间矛盾或记录缺失的标「重点催办」。

## 回收

律师说「核证回收」时：答复逐条对照现有证据，矛盾标出，同步更新对照表和相关文件；未答与「不知道」列进下一轮问卷。
