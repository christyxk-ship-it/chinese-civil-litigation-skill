# 开庭准备编

## 产物

1. **开庭提纲** .html：庭审信息（取自传票或法院送达页面并写明出处，口头转述的标「待核验」）→ 战术定位（这一庭拿什么、守什么，一两句，决定后面各节详略）→ 争议焦点 → 我方举证 → 质证要点 → 法官可能问 → 对方可能问 → 辩论要点 → 程序节点（不当场提就失权的）→ 携带清单 → 庭后动作。按诉讼地位配重：原告写厚举证，被告写厚质证。做过法官冷读、对方攻击的，「法官可能问」「对方可能问」先从两份报告里取。
2. **条件产出**：要核对书证原件的出核对预案（现场记录表能打印带走）；有程序问题的出程序性申请 .docx，不列被申请人。
3. **《庭上速查包》**：单文件、离线自包含 .html，带页内搜索，庭前拷进平板。只放五张表：证据速查｜法律问题立场｜红线｜法条原文（庭前全文预载）｜关键数字（带出处）。内容只从已定稿文件里抄已核验结论。

开庭日期取自传票，写进律师的期限待办。
