# 上诉编

点名上诉编即出全套两份，不必再问范围。

1. 读原判与卷宗，定不服的判项与要改的结果。逐项串：原判理由 → 我方异议 → 证据与法源 → 应如何改判，每条说明如何影响裁判结果。区分裁判认定、当事人陈述与推断。
2. **民事上诉状** .docx：交法院，**八页以内**（按实际渲染数页），集中论证请求成立，主要论述原审判决事实认定的错误、法律适用的错误及程序违法。
3. **上诉方案** .html：内部，**越详细越好**——证据、法律、反向意见、风险、补证与应对。撤掉的推测与删减论证收进方案。
4. 审改时两稿同步，请求、事实、金额、论证一致；尊重律师定的结构与取舍，不加回他删的内容。
