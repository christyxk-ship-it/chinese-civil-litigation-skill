# 庭前编

## 产物

1. **开庭提纲** .html：单文件、离线自包含、带页内搜索，庭前拷进平板，庭上只翻它。庭审信息（取自传票或法院送达页面并写明路径，口头转述的标「待核验」）→ 战术定位（这一庭拿什么、守什么，一两句，决定后面各节详略）→ 红线（庭上不能说的话、不能让的点）→ 争议焦点（每点我方立场一句话＋出处）→ 我方举证（带证据页码）→ 质证要点 → 法官可能问 → 对方可能问 → 辩论要点 → 程序节点（不当场提就失权的）→ 携带清单 → 庭后动作 → 附：法条原文（庭前全文预载）、关键数字（带出处）。按诉讼地位配重：原告写厚举证，被告写厚质证。做过法官冷读、对方攻击的，「法官可能问」「对方可能问」先从两份报告里取。内容只抄已定稿文件里核验过的结论。二审开庭的，写明一审判决「本院查明」或「经审理查明」部分具体认定错误之处，引具体语句并标对应页码、段落。

2. **代理意见** .docx：按争议焦点逐个写我方观点、理由、证据与法条原文，从范本起稿（见总则「出稿」），开庭前定稿。提纲「辩论要点」是它的压缩版，两者口径一致。
   - 每节标题就是该节结论，一句话；最能赢的论点放第一，退一步的写明「退一步说」作备位。
   - 正文标题不超过两级，连文书标题不超过三级。
   - 写事实认定和法律适用，证据三性归质证意见；我方拒绝作为证据的材料，我方也不引用。
3. **条件产出**：要核对书证原件的出核对预案（现场记录表能打印带走）；有程序问题的出程序性申请 .docx，申请对象为该阶段司法机关，不列对方当事人为被申请人。

开庭日经律师确认后写进期限待办，注明传票出处。
