# 举证编

通读全案材料，按抗辩体系分组（组内相互印证、组间对应争点），出证据目录 .docx 与证据卷 .pdf，两者页码逐字一致。证据本体内容一律不动。

## 证据目录

- A4 横向；首行「案号：【待定】」居中，标题「《XX》证据目录」一号居中，不列案件名行；表头跨页重复。
- 四列：编号 1.6cm｜证据名称 4.5cm（只写名称）｜证据内容和证明目的 14.7cm（固定两段：「证据内容：」客观描述是什么、谁出具、时间、编号、取得方式与形式；「证明目的：」可分①②③）｜页码 2.5cm（「第N–M页」，按 `page_map.json` 回填；视频类证据写「见光盘」）。
- 每组前一行合并、灰底、加粗：「第X组证据（证据N、N）共同的证明目的：……」，**尽可能简洁**，一两句。
- 落款三行右对齐：提交人全称｜委托诉讼代理人｜【】年【】月【】日。
- 附注另起一页：「附：待补证据与待确认事项（本部分为内部工作提示，正式提交前删除）」。分页符挂在落款日期行末，不另加空段（空段会顶出整页空白）。

## 证据卷

用 `scripts/build_evidence_pdf.py`，按 `scripts/config.example.json` 写配置（需先装 `pypdf`、`reportlab`、`pillow`）：

- 封面：「被告《XX》证据」（原告则「原告XX证据」）、案件名、案号【待定】、提交人全称（不加诉讼地位）、代理人、日期。
- 目录页 → 每项分隔页（「证据N」＋主标题，不带来源小字）→ 原件整页插入。
- 底部「第 X 页，共 Y 页」，封面起算。
- 我方排版文字用仿宋，自制的证据本体页（如对照表）用宋体区分。脚本按序找字体：配置 `fonts` 指定的 → WPS 自带仿宋 → Windows 仿宋 → macOS 系统宋体；都找不到就报错并提示在配置里指定。macOS 系统「华文仿宋」在部分版本上只有少量字形，不要指定它。
- 证据名称只在配置里写一处，目录、分隔页、docx 三处逐字一致；改名改配置重跑。
